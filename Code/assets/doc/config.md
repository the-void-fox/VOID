# Конфигурация системы

## Источник и сборка

```
/etc/system/*.vv  →  rebuild  →  поколение system/gen<N>  →  загрузка
  это пишете вы     вычисляет     лежит в store       читает ядро
```

Ваш текст система НЕ читает на загрузке. Она читает поколение — результат
вычисления. Отсюда всё остальное: правка конфига ничего не ломает, пока вы не
собрали; собранное остаётся навсегда, и к нему можно вернуться.

```
rebuild            собрать поколение из /etc/system/default.vv
gens               список поколений, активное помечено *
switch gen11       выбрать другое (действует после перезагрузки)
```

## Модули

`default.vv` — верхний файл, он склеивает остальные через `import`:

| файл | о чём |
|---|---|
| `services.vv` | службы: файлы, звук, беспроводная карта |
| `networking.vv` | сетевой сервис и резолвер имён |
| `terminal.vv` | чем встречает система: экран, шелл, клавиши, обои |
| `bar.vv` | что стоит в панели и в каком порядке |
| `apps.vv` | чем открывать: программы по умолчанию |
| `autostart.vv` | что открывается при входе |
| `hardware.vv` | железо, которое настраивает человек (тачпад) |
| `packages.vv` | пакеты, которые система обязана иметь |
| `net.vv` | сеть целиком: `true` или `false` |

Файлы — обычный vvsh: внутри можно считать, ветвиться, собирать списки.

## Строка запуска

Главные записи — `service` и `shell`. Обе называют программу и перечисляют её
права:

```
service("net-srv", "dev:net:rw", "store:r", "arg:dhcp=off")
shell("wm", "endpoint:posixfs", "store:rwx", "mmio:fb!", "power:wg!", "env")
```

Что бывает в этом списке — `doc caps`. Что бывает за пределами строки
запуска — `doc entries`.

## Строгость

`rebuild` не соберёт поколение, если в конфиге несуразица, и назовёт её:

```
vvsh: service net-srv: `stroe:r` — такого права нет
vvsh: поколение не собрано
```

Ловится: неизвестное право, чужая буква в правах, несуществующее устройство,
ссылка на необъявленный сервер, отсутствующая в store программа, ненайденный
корень.

Отдельно — предупреждение о потере: если новое поколение умеет меньше
прежнего, об этом скажут поимённо, но соберут. Убрать службу можно и нарочно;
молча потерять — нет.

## Секреты

Паролям в конфиге не место: его показывают, копируют и держат в поколениях.
Пароль — корень store, а в конфиге стоит его имя со знаком `@`:

```
vvsh/> secret wifi/ключ
значение (скрыто): *******
корень wifi/ключ задан (7 Б)
```

```
service("wifi", "mmio:wifi", "dma", "store:r", "netdev",
        "arg:ssid=ИМЯ СЕТИ", "arg:key=@wifi/ключ")
```

Знак `@` не украшение: по нему `rebuild` проверяет, что корень есть. Конфиг,
увезённый на другую машину без этого корня, не соберётся — и скажет, чего не
хватает.

## Если что-то пошло не так

- поколение собралось, а система не поднялась — выберите прежнее:
  `switch gen<N>` и перезагрузка;
- конфиг испорчен до неузнаваемости — `init-config --force` посеет шаблоны
  заново (ваши файлы будут перезаписаны);
- что именно сказала система на загрузке — `klog`.
