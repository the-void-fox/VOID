# vvsh — язык и шелл

Одна вещь служит двумя: vvsh — и командная строка, и язык, на котором написана
конфигурация системы. Это сделано нарочно: иначе пришлось бы учить два
синтаксиса и держать два разбора.

## Две строки, две роли

```
ls /etc              команда: голые слова
\1 + 2 * 3           выражение: ведущая обратная косая
```

Строка без `\` — команда: первое слово имя, остальные аргументы-строки.
Строка с `\` впереди вычисляется как выражение языка.

## Язык

Значения: числа, строки в кавычках, списки `[1, 2, 3]`, `true` и `false`.

```
x = 2 + 3                       определение
f = |a, b| a + b                функция
f(4, 5)                         вызов
if x > 4 { "много" } else { "мало" }
cond([x == 5, "пять"], [else, "другое"])
let([[a, 1], [b, 2]], a + b)    локальные имена
```

Списки: `append`, `car`, `cdr`, `cons`, `map`, `length`, `null?`.

Конвейер `|>` передаёт значение ПОСЛЕДНИМ аргументом:

```
\[1, 2, 3] |> length            → 3
\[1, 2] |> append([9])          → [9, 1, 2]
```

Тот же знак работает и в командной строке — см. ниже.

Импорт: `import("модуль.vv")` вычисляет другой файл и отдаёт его значение. Так
конфигурация разложена по файлам, а `default.vv` склеивает остальные.

## Команды

`help` — полный список. Чаще всего нужны:

| | |
|---|---|
| `ls` `cat` `cd` `pwd` `cp` `mv` `rm` `mkdir` `stat` | файлы |
| `run` `ps` `kill` | программы |
| `rebuild` `switch` `gens` `init-config` | система |
| `root` `root-del` `secret` `roots` | корни store |
| `ping` `resolve` `fetch` `send` | сеть |
| `doc` `klog` `date` `beep` `volume` | прочее |

## Конвейеры

Правило одно: команда ОТДАЁТ текст, печатает его шелл. Поэтому вывод любой
команды можно передать дальше.

```
klog |> grep wifi               журнал, только строки про wifi
cat /etc/system/net.vv          показать файл
klog > /etc/log.txt             записать в файл
cat /etc/log.txt |> send 192.168.0.87 9000       отправить на ПК
klog |> grep ошибка > /etc/beda.txt              отфильтровать и записать
```

- `|>` и `>>` — одно и то же, разделитель звеньев; звеньев сколько угодно;
- `>` в конце — записать итог в файл;
- звеном может быть и программа: её вывод шелл соберёт сам.

Пустое звено — ошибка вслух, а не пустой файл на той стороне.

## Кавычки

Слова режут пробелы, кавычки склеивают и в аргумент не попадают:

```
cat "/etc/мой файл.txt"
echo "[service(\"wifi\", \"mmio:wifi\")]" > /etc/system/services.vv
```

Внутри кавычек `\"` — кавычка, `\\` — обратная косая. Незакрытая кавычка —
ошибка вслух.

## Чего в языке нет

Циклов и изменяемых переменных. Это не упущение: язык описывает конфигурацию,
а она — значение, а не последовательность действий. Повторение выражается
через `map`, ветвление — через `if` и `cond`.
