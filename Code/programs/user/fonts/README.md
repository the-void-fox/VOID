# fonts — шрифт терминала

`FiraCodeNerdFontMono-Regular.ttf` — моноширинный шрифт с глифами Nerd Font (иконки лежат в
Private Use Area). Вшивается в бинарь `term` через `include_bytes!`.

**Почему в бинаре, а не в store.** Так первая версия терминала не упирается в разбиение больших
объектов на куски: 2.6 МБ одним объектом — отдельная работа, а доказать надо было другое (что
глифы вообще появляются на экране VOID). Перенос шрифта в store — следующий шаг; тогда же
шрифт станет сменяемым без пересборки, ради чего всё и затевалось.

Лицензия шрифта — SIL OFL 1.1 (FiraCode + патч Nerd Fonts).
