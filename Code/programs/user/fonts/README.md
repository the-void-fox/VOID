# fonts — шрифт терминала

**С Вехи 114 этот файл в бинарь НЕ вшивается.** `term` берёт шрифт снаружи:

1. `terminal("font", "имя.ttf")` в конфиге поколения — имя ищется в `share/fonts/**` у пакетов
   профиля (то есть шрифт ставится как обычный пакет: `packages("…")` в `packages.vv`);
2. `terminal("font", "/абсолютный/путь")` — берётся как есть;
3. ничего из этого не нашлось — рисуем **встроенным битмапным 8×16** (`src/bitfont.rs`, 4 КиБ,
   таблица подключается прямо из ядра). Некрасиво, но система поднимается и читается всегда.

**Что это дало.** `bin/term` похудел с 2 782 200 до 144 376 байт — в 19 раз. Вшитый шрифт был
срезанным углом, который уже отомстил: посев такого бинаря в store падал по куче ядра, и
терминал пришлось делать x86-only. Заодно шрифт стал сменяемым без пересборки — ради чего всё
и затевалось.

**Важное ограничение.** Шрифт обязан лежать в ДЕРЕВЕ ПАКЕТА (`/nix/store/…`): обычный файл
posixfs держит в слоте на 128 КиБ, и мегабайтный TTF туда не влезает. Раньше он приезжал молча
обрезанным, теперь `open` честно отказывает (та же Веха 114).

`FiraCodeNerdFontMono-Regular.ttf` оставлен в репозитории как эталон для проверок на хосте
(`ereb-render/examples`) и как исходник, если шрифт понадобится положить в store вручную.
