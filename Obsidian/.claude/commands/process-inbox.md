Обработай заметки в `00-inbox/`.

Для каждой заметки:
1. Определи тип: это заметка по проекту, справочная (reference), задача или ADR-кандидат.
2. Предложи целевую папку:
   - по проекту → `10-projects/<project>/notes/`
   - справочная атомарная → `20-reference/`
   - задача → `30-todo/`
   - архитектурное решение → `10-projects/<project>/adr/` (через /adr)
3. Добавь корректный frontmatter по схеме из CLAUDE.md (title, created, tags, status).
4. Приведи имя файла к kebab-case.
5. Проставь `[[wikilinks]]` на уже существующие связанные заметки.

ВАЖНО: сначала покажи план одной таблицей (файл → куда → новое имя → теги).
Жди подтверждения. Перемещай и редактируй только после «да».

Если передан аргумент ($ARGUMENTS) — обработай только заметку с этим именем, не весь инбокс.
