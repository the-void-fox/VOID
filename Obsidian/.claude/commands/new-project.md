---
description: Завести новый проект в 10-projects/
---

Заведи новый проект. Аргумент: `$ARGUMENTS` = имя проекта (kebab-case).

Шаги:
1. Создай структуру:
   ```
   10-projects/<name>/
   ├── README.md      (из templates/project.md)
   ├── adr/
   └── notes/
   ```
2. В README подставь имя проекта, сегодняшнюю дату, тег `project/<name>`, status: active.
3. Спроси коротко (одним сообщением): стек, путь к коду, одна строка описания —
   и заполни соответствующие поля README.
4. Покажи итоговый README.
