# VOID

> Микроядро на Rust/RISC-V, в основе которого — персистентное, контент-адресуемое,
> capability-защищённое пространство объектов. Ядро для операционных систем, а не клон Linux.

## Тезис
Все современные ОС — амнезики: при потере питания забывают всё в RAM, и поверх этого
факта выстроена башня костылей (файлы, сериализация, БД, save-системы, образы контейнеров,
само понятие «установка»). NixOS, Docker, снапшоты — заплатки над тем, что у ОС нет родного
понятия долговечного воспроизводимого состояния.

VOID берёт линию персистентных capability-систем (KeyKOS / EROS / Grasshopper) и оживляет её
тремя ингредиентами, которых в 90-х не было и которые чинят ровно те причины, по которым она
проиграла:
- **безопасность языка** (Rust) — изоляция без 30 лет CVE на ручной памяти;
- **контент-адресация + неизменяемость** (как Nix/git) — делает персистентность *безопасной
  и воспроизводимой*: откат бесплатен, «испорченного состояния» структурно не бывает;
- **async** — единое IO-тяжёлое пространство объектов быстрое и конкурентное с первого дня.

Центральный примитив — **объект**: неизменяемые значения адресуются по хэшу, изменяемые
«ячейки» ссылаются на значения через capability, всё живёт в персистентном single-level store.

## Стек
- Язык: **Rust** (`#![no_std]`).
- Платформа: **RISC-V** (`riscv64gc-unknown-none-elf`), QEMU `virt`, OpenSBI → S-mode ядро → U-mode userspace.
- Архитектура: **микроядро** + userspace-серверы. Слои совместимости (Linux/POSIX) — отдельные серверы поверх, не в ядре.
- Сборка: Cargo workspace. Окружение: `shell.nix` (Rust+target+QEMU+gdb).

## Код
- Путь: `../Code` (Cargo workspace)
- Точка входа: `Code/kernel/src/main.rs` → `kmain`
- Запуск: `nix-shell` → `cd Code && cargo run`

## Статус
**Фазы 0–3 закрыты (Вехи 1–22).** Тезис ADR 0002 полон, система самостоятельна: программы —
объекты store, исполняются по content-id ([[exec-from-store]]); живой shell `vsh` с вводом
([[interactive-shell]]); capability передаются по IPC и переживают перезагрузку вместе с
c-space ([[ipc-cap-transfer]]); у процессов ленивая куча и честные page fault
([[process-heap]]). Начата **Фаза 4 — мультиархитектурность и пакеты** ([[0004-void-pkg]]):
Веха 23 (userspace в ELF) → arch-рефакторинг → x86_64 bring-up; пакетная дорожка — std-порт
Rust, uutils, host-мост к nix. Развёрнутый план пакетов — [[void-pkg]].
